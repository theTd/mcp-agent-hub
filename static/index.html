          MCP 接入指南
        

        

        
      

      

        
任何支持 MCP 协议的宿主 Agent 接入下方地址后，即可调用 Hub 中的全部 Sub-Agent，并可按次指定任意已识别的 model 与 thinking_level。

        

          
1添加 MCP 服务器（Streamable HTTP，推荐）

          

            

            
          

        

        

          
2在主 Agent 中调用，可动态指定模型与思考等级

          

            
spawn_subagent(
  agent_type="omp",
  task="分析并重构模块",
  model="kimi-code/k3.1-pro",
  thinking_level="max",
  env={"CUSTOM_FLAG": "1"}
)

            
          

        

        

          
3暴露的 MCP 工具

          

            
list_agent_profiles列出所有可调用的 Profile、路由指南与模型开关状态。

            
discover_agent_models_and_thinking_levels重新扫描本机引擎的模型与思考等级，并返回可用列表。

            
spawn_subagent按指定 Profile、模型与思考等级启动一个 Sub-Agent 会话。

            
get_subagent_status_and_trace查询会话执行到第几步、调用了哪些工具与当前活动。

            
get_subagent_final_response读取会话的最终回复与任务总结，进程结束后仍可查询。

            
send_to_subagent向运行中的 Sub-Agent 发送消息或补充指令。

            
reply_to_subagent回复 Sub-Agent 的提问或审批请求，解除它的等待。

            
respond_to_subagent_approval_or_choice代批高风险操作，或代选 Sub-Agent 的交互选项。

            
wait_subagent_events同步兜底监听工具（仅限不支持后台 Shell 命令的宿主使用；常规请后台异步跑 background_poll_command）。

            
summarize_subagent_transcript解析引擎原生日志，返回高信噪比的执行摘要。

            
read_subagent_screen读取 Sub-Agent 的终端画面，可选择附带原始 TUI 文本。

            
list_active_sessions列出正在运行的会话，以及持久化的历史会话。

            
resume_subagent恢复已结束或已归档的会话（沿用同一个 session_id），可顺带送入一条消息。

            
list_archived_sessions列出归档会话：结束原因、结束时间、是否可恢复与不可恢复的原因。

            
terminate_subagent终止指定会话，并持久化它的最终回复。

            
attach_desktop_gui_window按窗口标题把本机桌面窗口纳入总控台投屏。
